# 文档目录（docs）

本目录用于集中管理项目文档。

> 说明：图片与截图资源由你后续补充，建议统一放在 `docs/assets/` 下。

## 分区结构

- `01-快速开始/`：面向新用户的最短上手路径
- `02-安装部署/`：安装、运行环境、部署相关说明
- `03-使用指南/`：日常操作流程与场景化示例
- `04-功能说明/`：各功能模块的详细介绍
- `05-配置与个性化/`：配置项、参数、主题与自定义
- `06-常见问题/`：FAQ、排障与已知问题
- `07-版本与发布/`：版本记录、升级说明、发布流程
- `08-开发与贡献/`：开发规范、目录结构、贡献流程
- `assets/`：文档图片、流程图、示意图等静态资源

## 建议命名规范

- 文档文件名建议使用中文语义化命名，例如：`功能总览.md`、`安装说明.md`。
- 若需排序展示，建议文件名前加两位序号，例如：`01-环境准备.md`。

## 推荐起步文件（可按需创建）

你可以从以下文件开始补充内容：

- `01-快速开始/快速开始.md`
- `02-安装部署/安装说明.md`
- `03-使用指南/基础操作.md`

- `06-常见问题/FAQ.md`
- `07-版本与发布/更新日志.md`
- `08-开发与贡献/贡献指南.md`
